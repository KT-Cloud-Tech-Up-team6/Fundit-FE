# 구매자 다시보기·숏 클립 와이어프레임

## Design Source

- [지정 Figma 영역](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=645-6663)의 9월 10일 10:35, 10:41 추가 이력을 반영한다. [Issue #67](https://github.com/KT-Cloud-Tech-Up-team6/Fundit-FE/issues/67).
- FL_B_LV_VOD_1(811:7811)은 기본 채팅, FL_B_LV_VOD_2(811:7887)는 구간 탐색, FL_B_LV_VOD_3(815:8114)는 숏 클립이다.

## 확인 경로

- `/live/demo-live?mode=replay`에서 채팅·구간 탐색을 전환한다.
- `/live/demo-live?mode=replay&view=clip`에서 숏 클립을 확인한다. 별도 URL 경로를 만들지 않고 다시보기의 표시 쿼리로 구분한다.
- Storybook `Features/BuyerLive/Replay`의 Default, Chapters, Clip.
- `/live/demo-live`는 기존 실시간 화면이다. 새로운 화면도 전용 헤더만 사용하고 OS 상태바·홈 인디케이터는 복제하지 않는다. 넓은 화면은 390px 중앙 정렬한다.

## 원본 상태와 목업 경계

- 다시보기 진입 시 채팅이 선택된다. 채팅과 구간 탐색의 선형·채움 아이콘을 구분한다.
- 구간 목록은 가로 스냅 스크롤, 선택 테두리, 3줄 설명과 예시 이미지로 구성한다. 클릭 시 로컬 선택·진행률·재생 상태를 변경한다. 이전·다음은 구간 끝에서 비활성화한다.
- 원본은 모든 시간이 0이고 진행 막대는 약 37.5%, 첫 구간은 선택 상태다. 초기 디자인 예시는 유지하고 실제 영상 길이·타임스탬프로 해석하지 않는다. 목업 구간 시작점은 0·50·75·90%이며 선택 구간을 진행률에서 계산한다. 초기 상태의 다음 구간 이동은 37.5%에서 50%로 진행한다. Storybook InitialNextChapter에서 역행 방지와 양 끝 경계를 확인한다.
- 실제 영상이 없어 시간은 증가하지 않는다. 재생 버튼은 로컬 재생·일시정지 상태만 전환한다. 실제 자동 재생과 영상 동기화는 미연결이다.
- 팔로우·좋아요는 로컬 토글, 공유는 현재 숏 클립 URL 복사, 전체 화면은 브라우저 Fullscreen API다. 안내는 4초 뒤 사라진다.
- Q&A·숏 클립 채팅의 추가 상태와 연결된 프로젝트 ID는 제공되지 않았다. 해당 버튼은 목업 안내만 표시하며 기존 실시간 Q&A를 임의로 이식하거나 liveId를 projectId로 사용하지 않는다.
- 기존 프로젝트 상세 영상 카드 역시 영상 식별자가 없으므로 이번 목업 URL에 임의 연결하지 않는다.
- API·영상·인증·영구 저장은 제외한다. 기존 공유·하트·확대·질문·종료·펀딩·시청자 아이콘을 재사용하고 다른 도형은 Figma 원본 SVG를 사용한다.

## 검증 범위

- Storybook에서 초기 채팅, 패널 전환, 구간 선택·재생 재개, 진행률, 팔로우·좋아요와 미연결 안내를 확인한다.
- 320·390·1280px의 배치·넘침과 기존 실시간·프로젝트 경로를 확인한다. 실제 영상 및 모바일 기기의 전체 화면 지원은 별도 검증 대상이다.
