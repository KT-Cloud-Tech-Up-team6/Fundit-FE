## 원본 상태와 목업 경계

- 다시보기 진입 시 채팅이 선택된다. 채팅과 구간 탐색의 선형·채움 아이콘을 구분한다.
- 타임라인은 선택 구간의 자동 중앙 스냅 스크롤(양 끝은 스크롤 범위 내 정렬), 파란 선택 테두리, 시간·한 줄 제목·유형 배지로 구성한다. 클릭 시 로컬 선택·진행률·재생 상태를 변경한다. 이전·다음은 구간 끝에서 비활성화한다.
- 플레이어의 시간은 모두 0이고 진행 막대는 약 37.5%, 첫 구간은 선택 상태다. 타임라인의 00:11·02:34·03:15·04:04는 Figma 표시 예시이며 실제 seek 시각이 아니다. 초기 디자인 예시는 유지하고 실제 영상 길이·타임스탬프로 해석하지 않는다. 목업 구간 시작점은 0·50·75·90%이며 선택 구간을 진행률에서 계산한다. 초기 상태의 다음 구간 이동은 37.5%에서 50%로 진행한다. Storybook InitialNextChapter에서 역행 방지와 양 끝 경계를 확인한다.
- 방송 포스터·상품·판매자 이미지는 기존 Figma 로컬 에셋을 재사용한다. UI 데이터는 `model/replay-demo.ts`에 분리한다.
- 쇼츠에 원본 안내 자막과 강조 자막을 표시한다. 강조 자막만 공식 배포 Gmarket Sans Medium·Bold WOFF2를 사용하며 라이선스는 `public/fonts/GmarketSans-LICENSE.txt`에 보관한다. 출처는 https://corp.gmarket.com/fonts/ 및 공식 웹폰트 https://script.gmarket.com/fonts/ 이다. 폰트는 자막을 표시할 때 로드하며 전체 앱 폰트는 바꾸지 않는다.
- 공용 Avatar·Badge·Button·Icon을 재사용한다. 신규 요소는 Tailwind로 배치하고 기존 CSS Module의 슬라이더 가상 요소·선택 상태·가로 스크롤을 유지한다. Figma 검정 50% 그라데이션과 80% 자막 배경은 대응 semantic 토큰이 없어 원본 alpha를 사용한다.
- 실제 영상이 없어 시간은 증가하지 않는다. 재생 버튼은 로컬 재생·일시정지 상태만 전환한다. 실제 자동 재생과 영상 동기화는 미연결이다.
- 팔로우·좋아요는 로컬 토글, 공유는 현재 숏 클립 URL 복사, 전체 화면은 브라우저 Fullscreen API다. 안내는 4초 뒤 사라진다.
- Q&A·숏 클립 채팅의 추가 상태는 미연결 안내를 유지한다. 알려진 방송의 제품 카드 본문은 app에서 전달받은 명시적인 목업 관계로 프로젝트 상세에 연결한다. 1087:17233의 가격·5+ 더보기 구조를 적용하고, 더보기는 단일 선택 리워드 시트를 연다. 채팅 아이디는 지정 색상 #DEDEDE를 사용한다. 가격과 리워드는 목업이며 선택값의 주문서 전달은 별도 작업이다.
- 프로젝트 상세에서 다시보기·숏 클립 목업으로 진입할 수 있다. 개별 영상별 재생 데이터는 아직 없으며 같은 방송의 데모 플레이어를 사용한다.
- 주석 1055:15731에 따라 390px 화면에서 다시보기 채팅·제품 카드의 너비는 290px, 오른쪽 동작과 간격은 12px다.
- API·영상·인증·영구 저장은 제외한다. 기존 공유·하트·확대·질문·종료·펀딩·시청자 아이콘을 재사용하고 다른 도형은 Figma 원본 SVG를 사용한다.
