## 원본 상태와 목업 경계

- 다시보기 진입 시 채팅이 선택된다. 채팅과 구간 탐색의 선형·채움 아이콘을 구분한다.
- 타임라인은 선택 구간의 자동 중앙 스냅 스크롤(양 끝은 스크롤 범위 내 정렬), 파란 선택 테두리, 시간·한 줄 제목·유형 배지로 구성한다. 클릭 시 로컬 선택·진행률·재생 상태를 변경한다. 이전·다음은 구간 끝에서 비활성화한다.
- 플레이어의 시간은 모두 0이고 진행 막대는 약 37.5%, 첫 구간은 선택 상태다. 타임라인의 00:11·02:34·03:15·04:04는 Figma 표시 예시이며 실제 seek 시각이 아니다. 초기 디자인 예시는 유지하고 실제 영상 길이·타임스탬프로 해석하지 않는다. 목업 구간 시작점은 0·50·75·90%이며 선택 구간을 진행률에서 계산한다. 초기 상태의 다음 구간 이동은 37.5%에서 50%로 진행한다. Storybook InitialNextChapter에서 역행 방지와 양 끝 경계를 확인한다.
- 방송 포스터·상품·판매자 이미지는 기존 Figma 로컬 에셋을 재사용한다. UI 데이터는 `model/replay-demo.ts`에 분리한다.
- 쇼츠에 원본 안내 자막과 강조 자막을 표시한다. 강조 자막만 공식 배포 Gmarket Sans Medium·Bold WOFF2를 사용하며 라이선스는 `public/fonts/GmarketSans-LICENSE.txt`에 보관한다. 출처는 https://corp.gmarket.com/fonts/ 및 공식 웹폰트 https://script.gmarket.com/fonts/ 이다. 폰트는 자막을 표시할 때 로드하며 전체 앱 폰트는 바꾸지 않는다.
- 공용 Avatar·Badge·Button·Icon을 재사용한다. 신규 요소는 Tailwind로 배치하고 기존 CSS Module의 슬라이더 가상 요소·선택 상태·가로 스크롤을 유지한다. Figma 검정 50% 그라데이션과 80% 자막 배경은 대응 semantic 토큰이 없어 원본 alpha를 사용한다.
- 실제 영상이 없어 시간은 증가하지 않는다. 재생 버튼은 로컬 재생·일시정지 상태만 전환한다. 실제 자동 재생과 영상 동기화는 미연결이다.
- 팔로우·좋아요는 로컬 토글, 공유는 현재 숏 클립 URL 복사, 전체 화면은 브라우저 Fullscreen API다. 안내는 4초 뒤 사라진다.
- Q&A·숏 클립 채팅의 추가 상태는 미연결 안내를 유지한다. 알려진 방송의 제품 카드 본문은 app에서 전달받은 명시적인 목업 관계로 프로젝트 상세에 연결한다. 1087:17233의 가격·5+ 더보기 구조를 적용하고, 더보기는 단일 선택 리워드 시트를 연다. 채팅 아이디는 지정 색상 #DEDEDE를 사용한다. 가격과 리워드는 목업이며 선택값의 주문서 전달은 별도 작업이다.
- 프로젝트 상세에서 다시보기·숏 클립 목업으로 진입할 수 있다. 개별 영상별 재생 데이터는 아직 없으며 같은 방송의 데모 플레이어를 사용한다.
- 주석 1055:15731에 따라 390px 화면에서 다시보기 채팅·제품 카드의 너비는 290px, 오른쪽 동작과 간격은 12px다.
- API·영상·인증·영구 저장은 제외한다. 기존 공유·하트·확대·질문·종료·펀딩·시청자 아이콘을 재사용하고 다른 도형은 Figma 원본 SVG를 사용한다.

## 데스크톱 확장 #156

- [지정 섹션 `1525:43622`](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=1525-43622)의 다시보기 채팅 `1525:43800`, 구간 탐색 `1525:43988`, 시연 영상·숏 클립 `1525:44165`를 적용한다. VOD_3의 화면 정의는 구간 탐색으로 중복돼 있지만 실제 화면의 시연 영상 배지·AI 제목·자막을 기준으로 숏 클립에 연결한다.
- 1200px 이상에서 공통 3열 배치를 사용하고 나가기·상세 정보 보기는 시청과 같은 경로로 연결한다. Q&A는 기존 안내-only 동작 대신 시청과 같은 중앙 모달을 연다. 1200px 미만은 기존 모바일 UI와 안내 동작을 유지한다.
- 사용자 승인에 따라 데스크톱 다시보기·숏 클립 채팅에도 실시간과 같은 로컬 전송·금칙어 예시 차단을 추가한다. 채팅/타임라인을 전환해도 현재 화면의 작성 중 내용과 보낸 메시지는 유지한다. 영상 시각과 동기화된 기록이나 서버 채팅이 아니다.
- 타임라인 `1525:44139`는 VERTICAL 배치인데 overflow 속성은 HORIZONTAL로 남아 있다. 승인된 기준대로 세로 배치·스크롤바를 따라 데스크톱은 세로 탐색하고, 기존 모바일 가로 탐색은 유지한다. 선택 항목 중앙 스크롤은 양 끝에서 스크롤 범위로 제한한다.
- `1525:43616/43618`의 클릭 상태 전환을 확인해 재생·일시정지를 구현한다. 기존 목업 진행률 37.5%, 구간 시작점 0/50/75/90%, 표시 시각 00:00:00을 재사용한다. 이전/다음 경계에서 버튼을 비활성화하고 재생 버튼으로 포커스를 옮긴다. 실제 영상 재생·seek는 미연동이다.
- 숏 클립은 처음에 타임라인을 표시하고 시연 영상 배지, AI 제목 예시, 상단 2줄 안내 자막과 Gmarket Sans 강조 자막을 표시한다. 이는 생성 결과 예시이며 실제 AI 생성·자막 동기화를 구현한 것이 아니다.
- 실시간의 공유·좋아요와 달리 데스크톱 다시보기·숏 클립은 원본처럼 Q&A·채팅·타임라인을 노출한다. 모바일의 기존 공유·좋아요·전체 화면은 유지한다.

## 실제 다시보기·쇼츠 연결 (#270·#272·#317)

- UUID 라이브의 `/live/{UUID}?mode=replay`는 `GET /vod`로 영상을 재생하고, `GET /highlights/public`의 `markers`로 구간 탐색을 그린다. 구간 시각은 초 단위로 받아 영상 길이 대비 진행률로 표시하고, 구간을 누르면 해당 초로 이동한다. 공개 하이라이트 조회는 조회수로 잡혀 화면당 한 번만 부른다.
- #317부터 구간 유형 배지는 BE enum 대신 AI 요구서의 7종 표시명(도입·가격·혜택·시연·스펙·기능·비교·질문 응답·마무리)을 쓰고, 모르는 값은 기타로 적는다. 데모 구간 라벨도 같은 기준으로 바꿨다(Figma 예시의 02:34 "질문 응답"은 AI 초기 버전의 오분류라 가격·혜택).
- `?mode=replay&view=clip&clip={highlightId}`는 `clips`에서 해당 쇼츠의 `clipUrl`을 재생한다. `clip`이 없거나 맞지 않으면 첫 재생 가능한 쇼츠, 쇼츠가 없으면 "공개된 쇼츠가 없습니다."와 다시보기 이동 링크를 보여 준다. 클립 화면은 VOD 재생 정보와 구간 탐색을 쓰지 않는다(쇼츠는 따로 렌더된 영상이라 방송 구간과 시각이 맞지 않는다).
- 쇼츠 제목은 `clips[].title`, 배지는 DEMO면 시연 영상, 그 외는 하이라이트다(Figma 배지 두 종류, 2026-09-23 결정). AI가 제목·자막을 영상에 번인하므로 실제 쇼츠에는 Figma 예시 자막을 겹쳐 그리지 않는다. 세로 영상이라 재생 영역 높이를 채우고, 번인 자막이 잘리지 않게 영상 맞춤은 contain을 유지한다. 모바일 공유 링크에는 `clip`을 포함한다. 데스크톱은 Figma 위치(왼쪽 패널)에 제목만 그린다.
- #317부터 실제 다시보기도 Figma 재생바(진행 슬라이더·`00:00:00` 시각·이전/재생/다음 구간)를 쓰고 브라우저 기본 컨트롤을 끈다. 재생 위치·재생 여부는 영상이 소유하고 재생바는 표시·전환만 한다. 첫 구간 전이거나 구간이 없으면 이전·다음 구간 이동을 막는다. 영상은 16:9 틀 대신 화면(데스크톱은 영상 영역)을 채우되 가로 VOD·번인 자막이 잘리지 않게 contain과 검정 여백을 쓴다. 데스크톱 실제 경로도 다시보기·쇼츠 배지를 Figma 배지로 표시한다. 데스크톱 실제 다시보기는 영상을 가운데 열에 두고, 구간별로 불러와 처음에 비기 쉬운 채팅 대신 구간 탐색 패널부터 연다(2026-09-23 검수 의견, Figma 기본값은 채팅). 채팅이 비면 "이 구간의 채팅이 없습니다."를 보여 준다. Figma 모바일 쇼츠에는 재생바가 없어 모바일 쇼츠만 기본 컨트롤을 유지하고, 라이브 시청은 바꾸지 않았다.
- 제외: 범례(Figma 원본 없음, 2026-09-23 결정), 프로젝트 상세 LIVE 체크 탭의 종료 라이브·쇼츠 목록(구매자가 프로젝트의 종료 라이브를 조회할 BE API 없음), 판매자 하이라이트 관리·공개 설정.
- 검증: 격리 Playwright에서 API를 가로채고 로컬 테스트 영상(16:9 VOD, 9:16 쇼츠 2개)을 Range 지원 서버로 서빙해 390×844·1440×900에서 구간 라벨·시킹, 재생바(기본 컨트롤 해제·시각·재생/일시정지·슬라이더와 키보드 시킹·다음 구간·첫 구간 전 경계), 쇼츠 기본·id 지정·잘못된 id·VOD 409·쇼츠 없음·공유 링크·데모 유지를 확인했다. 실제 BE·AI 서버의 쇼츠 재생은 미검증이다.
