# 구매자 프로젝트 상세 디자인

## API 연결 범위 (#195)

- 진행 중(ONGOING) 프로젝트의 펀딩 버튼은 공통 FundingCta를 사용합니다. 실제 UUID 주문 흐름은 PR #206과 함께 검증·반영해야 하며, 종료·준비중 프로젝트에서는 참여 버튼을 비활성화합니다.

- `/search`와 `/categories/{대분류}/{소분류}`는 BE 검색·카테고리 API의 정렬, 종료 필터, 페이지를 URL로 유지한다. 검색 초기 화면의 프로젝트는 홈 인기 피드이며 개인화 추천이 아니다.
- `/projects/{UUID}`는 공개 상세·리워드·환불정책·공지 목록·커뮤니티·LIVE 검증 정보를 조회한다. 기존 `demo-project`는 디자인 확인용 경로다.
- 목록 응답의 프로젝트 ID는 Long이고 상세 요청은 UUID다. 매핑 계약이 없어 목록의 상세 이동을 비활성화했다. 표시 코드나 숫자를 UUID로 변환하지 않는다.
- 공지 본문, 메이커·서포터 정보, 실제 영상, 찜과 결제 승인은 이 변경에 포함하지 않는다. 서버가 제공하지 않는 통계·AI 요약을 목업 값으로 채우지 않는다.
- 비로그인 세션 확인 완료 후 공개 조회를 시작한다. 실패 시 오류·재시도를 제공하며 목업 성공으로 대체하지 않는다.
- 390px·1200px 독립 headless 브라우저에서 테스트 응답으로 검색·페이지 이동·뒤로가기·실패 재시도·카테고리 이동·UUID 상세·새로고침을 검증했다. 실제 Gateway 환경과 BE 통신은 미검증이다.

## 구현 범위

- 전용 헤더, Figma 상품·방송 이미지, 판매자·펀딩 정보, AI 요약, 가로 탭, 상품 소개 이미지, LIVE 콘텐츠 목록, 찜·펀딩 하단 버튼을 구현한다.
- 원본 SVG와 상품 소개 이미지를 사용한다. 동일한 공유·찜·질문 아이콘과 기존 리워드 선택 시트를 재사용한다.
- 찜은 로컬 상태다. 공유는 현재 프로젝트 탭 URL을 복사한다. 안내 버튼은 클릭으로 열고 Escape 또는 포커스 이탈로 닫는다.
- 안내 툴팁은 primary 배경·inverse 글자·왼쪽 꼬리·11px Medium·한 문단을 적용한다. 작은 화면에서는 화면 안에 들어오도록 너비를 줄인다. Storybook LiveInformationTip에서 LIVE Q&A 안내도 확인한다.
- 두 탭 모두 원본의 `9999+` 축약 표시를 유지하며 찜 버튼은 로컬 상태로 토글한다.
- 진행 중 라이브 썸네일은 연결된 방송으로, 다시보기·숏 클립 카드는 연결된 방송의 목업 재생 화면으로 이동한다. 영상 카드는 같은 데모 플레이어를 사용하며 개별 영상 재생은 미연결이다. 상품 이미지 카운터도 정적 예시다.
- 달성률 `120,000%`, 모금액 `1,200,000,000 / 1,000,000원`, 탭의 `000`은 Figma 목업 값이다. `model/project-demo.ts`에서 UI 데이터로 관리하며 API DTO로 사용하지 않는다.
- Q&A는 원본대로 5개 표시한다. 상품 소개의 파란 개발 지시 문구와 안내용 딤은 사용자 화면에서 제거한다. 실제 AI 업로드 기능은 미연결이다. 예정 목업에서는 진행 중 방송 배너와 라이브 요약을 숨기며, 생략 지시 문구를 화면에 출력하지 않는다.
- 공용 Badge·Tooltip·FundingCta를 재사용한다. 신규 배치는 Tailwind를 사용하고 기존 CSS Module의 선택자·이미지 크롭·툴팁 배치를 유지한다. 회색 와이어프레임 색상은 semantic 토큰으로 교체한다. 탭은 기존 Next Link의 `scroll={false}`를 유지한다.
- 리워드 선택은 [최신 결제 플로우 지시문](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=1132-15072)을 따른다. 2026-09-17 사용자 확인으로 기존 단일 선택 정책을 대체했다. 새 리워드는 맨 위에 누적하고 기존 수량은 유지한다. 드롭다운을 다시 열면 선택 목록은 최대 128px로 스크롤한다.
- 상세의 `펀딩하기`로 시트를 열고 선택·수량을 메모리 세션으로 주문서에 전달한다. 스타터는 정가 219,900원·판매가 199,000원·무료배송이다. 배송지·쿠폰·적립금·카드·할부와 데모 완료 화면까지 연결하며 실제 청구·주문 API는 포함하지 않는다.
- API·실제 영상 재생·영구 저장·권한 검증은 포함하지 않는다.

## 라우팅 경계

- 프로젝트 페이지를 `(buyer-project)` 그룹에 두고 두 구현 탭에만 전용 화면을 적용한다. URL은 바뀌지 않는다.
- 나머지 기존 허용 탭은 BuyerShell과 placeholder를 유지한다. 알 수 없는 탭은 기존처럼 story로 처리한다.
- app에서 상세 화면과 FundingCta를 조합한다. 상세 기능은 리워드 선택 기능을 직접 import하지 않는다.

- #114: 상세 탭·종료된 라이브·숏 클립 목록은 공용 `useHorizontalDrag`로 데스크톱 마우스 드래그를 지원하며 스크롤바는 항상 숨긴다. 6px 이상 움직인 드래그 뒤의 클릭은 막고 일반 클릭·키보드·모바일 네이티브 스크롤은 유지한다. 세로 휠을 가로 이동으로 강제 변환하지 않는다.

- #118: 리워드 선택 시트에 240ms 아래→위 열기·위→아래 닫기와 딤 전환을 적용한다. 상세·라이브·다시보기에서 동일하게 재사용하며 `prefers-reduced-motion: reduce`에서는 전환을 생략한다. CSS `display`·`overlay` 전환을 지원하지 않는 브라우저에서는 닫기 모션이 즉시 종료될 수 있다.

## 데스크톱 확장 #154

- [섹션 `1419:48997`](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=1419-48997)의 상세 `1419:52879`, LIVE 체크 `1419:53057`을 적용한다. 일부 화면 정의에 남은 판매자 센터 문구는 사용자 승인에 따라 구매자 canonical route를 유지한다.
- 1200px 이상에서 왼쪽 714px·오른쪽 446px·사이 40px로 배치한다. `1419:53377/53380`의 상세 탭은 상단에 고정한다. 왼쪽 본문은 페이지 세로 스크롤(`1419:53376/53381`), 오른쪽 정보·펀딩·리워드 안내는 sticky와 창 높이에 따른 내부 스크롤(`1419:53375/53379`)을 사용한다. 짧은 창에서도 마지막 리워드까지 접근할 수 있다.
- 영상 목록의 가로 스크롤(`1419:53374/53378`)과 정보 아이콘 클릭 툴팁(`1419:53373/53371`)을 반영한다. 종료 방송 2개·숏 클립 5개·Q&A 5건의 실제 원본 문구를 목업 데이터로 사용한다. 사용자가 승인한 대로 건수는 목록에서 계산하며 LIVE 다시 보기 총 건수는 7건이다. 원본의 상품 설명은 검증된 성능이나 실제 AI 분석 결과가 아니다.
- `1443:42564`의 LIVE 배지 M 변경을 적용한다. 데스크톱 찜 표시는 원본의 2.4천+이고 모바일은 기존 9999+를 유지한다. 상태 토글·공유·펀딩하기로 여는 리워드 선택 및 주문서 흐름은 재사용한다.
- #170에서 최신 리워드 선택 `1541:49968/50148/50284`를 반영했다. 1200px 이상에서는 오른쪽 정보 아래 드롭다운에서 리워드를 복수 선택하고 수량·삭제·합계를 조작한다. 새 선택은 맨 위에 추가하며 기존 수량을 유지한다. 목록을 다시 열면 선택 목록은 최대 128px로 스크롤한다. 선택 전 펀딩하기는 목록을 열고, 유효한 선택 후에는 같은 장바구니를 실제 주문서로 전달한다. `RewardSheet`의 선택·옵션·금액·주문 세션 로직을 인라인 폼과 모바일 시트에서 공유한다. 모바일 시트가 열린 채 1200px 이상으로 바꾸면 시트를 닫는다.
- #170의 실제 앱 검증에서 1440·1200·1199·390px 선택/삭제/수량과 617,000원 주문서 전달·뒤로 가기를 확인했다. 고정 탭·우측 내부 스크롤·540px 높이 CTA 접근·가로 드래그·LIVE Q&A 툴팁도 검사했다. LIVE 배지는 웹 M/모바일 S와 흰 글자로 표시한다. 최신 LIVE 체크 `1541:50459`, 툴팁 지시 `1541:50705`와 대조했으며 섹션의 prototype reaction·개발자 annotation은 검사 결과 없었다. 별도 웹 결제 섹션은 포함하지 않았고, 공통 반응형 #165 통합은 별도다.
- `1419:53372`는 AI 스토리 생성 이미지가 표시될 영역 지시로 반영했다. 지시문·박스·딤은 사용자 화면에 출력하지 않고 기존 이미지 목업을 사용한다. 실제 자동 업로드는 API/AI 연동 대기다. 라이브 미진행 시 요약 생략 조건도 유지한다.
- 판매자 스토리 미리보기는 기존 모바일 배치를 유지한다. 검색·다른 상세 탭 placeholder, 영상 재생·권한·영구 저장 등 기존 보류 범위는 그대로다.
