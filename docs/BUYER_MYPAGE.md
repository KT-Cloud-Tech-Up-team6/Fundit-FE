## 구현 범위

- 기존 /my 경로에서 프로필 아이콘·마스킹 이메일·판매자 전환 버튼·등급·혜택·4개 메뉴 그룹을 반영한다. 이름·등급·혜택은 목업이며 정책 계산이나 실제 권한 전환은 구현하지 않는다.
- 관심 목록·환불 내역·알림·설정·고객센터는 기존 경로를 유지한다. 미구현 목적지는 이번 작업에서 새로 만들지 않는다. 제작/배송 현황은 주문을 임의 선택하지 않고 /my/fundings로 연결한다.
- 판매자 전환은 기존 /seller/projects로 이동한다. 화면 모드는 기존 /my/settings로 이동한다.
- 1199px 이하에서는 계정 상단바와 compact 하단 메뉴를 재사용한다. 1200px 이상에서는 공통 구매자 데스크톱 헤더·breadcrumb·793px 콘텐츠 열을 사용하고 하단 메뉴를 숨긴다. compact 하단 메뉴는 54px + safe area, 선택 아이콘과 비선택 색상을 사용한다. OS 홈 인디케이터는 복제하지 않는다.
- Tailwind·공통 semantic 토큰을 사용한다. 하단 메뉴의 상태 선택자·safe area는 기존 CSS Module에 추가한다.

## 검증

- Storybook의 주요 링크와 하단 마이 선택 상태.
- 실제 관심 목록 진입·뒤로가기, 320/390/1440px 화면 폭과 메뉴 가림 여부를 headless 브라우저로 확인한다.
