# 구매자 마이페이지

## Design Source

- [마이페이지 메인 `889:9089`](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=889-9089).
- `/my`를 전용 `(buyer-mypage)` 그룹에 두며 기존 다른 구매자 화면은 유지한다.

## 구현 범위

- 프로필·마스킹 이메일·회원 등급·혜택과 4개 메뉴 그룹을 표시한다. 등급 조건과 혜택은 Figma의 예시 문구이며 정책 계산을 구현하지 않는다.
- 관심 목록·환불 내역·알림·설정·고객센터 등은 기존 canonical route로 이동한다. 목적지 중 기존 placeholder 화면은 이 PR에서 구현하지 않는다.
- 제작/배송 현황은 프로젝트 선택이 필요하므로 `/my/fundings`로 진입한다. 임의의 주문 ID를 선택하지 않는다.
- 화면 모드는 기존 `/my/settings`에 연결하며 새 테마 정책을 추가하지 않는다.
- 판매자 버튼은 기존 `/seller/projects`로 이동한다. 실제 권한 전환·동의·로그인 가드는 기존 미확정 정책에 따라 후속 구현한다.
- 관심 목록 PR의 계정 상단바와 기존 구매자 하단 메뉴를 재사용한다. 새 스타일은 Tailwind CSS로 작성한다.

## 검증

- Storybook `Features/BuyerMyPage/Default`에서 주요 목적지와 하단 마이 선택 상태를 검증한다.
- 원본 이메일 글자색 `#959595`는 흰 배경 대비가 2.99:1로 접근성 검사에서 경고된다. 색상 변경은 디자인 확인 후 반영한다.
