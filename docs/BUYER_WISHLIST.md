# 구매자 관심 목록

## API 연결 (#196)

- `/my/wishlist`는 회원별 `GET /api/v1/wishes`를 조회한다. `page` 쿼리와 뒤로가기를 유지하며 해제(DELETE)·해제 취소 등록(PUT) 후 재조회한다. 실패 시 성공 상태로 바꾸지 않는다.
- `page`가 마지막 페이지보다 뒤면 [이전 페이지]는 `totalElements`와 페이지 크기로 센 마지막 페이지(0건이면 첫 페이지)로 간다(#374, `shared/lib/previous-page.ts`).
- BE PR #110의 `projectPublicId` UUID로 제목·썸네일에서 공개 상세로 이동한다(#250). 찜 해제·재등록에는 기존 숫자 `projectId`를 유지한다. UUID가 null이면 상세 링크 대신 정보 준비 중 안내를 표시하며 임의로 ID를 변환하지 않는다.
- 응답에 없는 달성률·판매자·광고를 예시 데이터로 채우지 않는다. 제목·썸네일은 nullable로 처리한다.

## 팔로잉 탭 연결 (#384)

- `?tab=sellers`는 `GET /api/v1/follows`를 20명씩 이어 읽는다(BE 정렬: 팔로우한 최신순). 목록 끝이 보이면 다음 페이지를 불러오는 무한 스크롤이고(#398, 요청서 PD-9), 찜 탭의 `page` 쿼리·[이전 페이지]·[다음 페이지]는 쓰지 않는다. 목록 위에 "총 N개"를 보이고, 빈 목록은 "팔로우한 판매자가 없습니다."다.
- 행은 Figma `FL_B_LK_LIST_2`(`1249:24108`)의 `SellerRow`를 쓴다. 이름은 닉네임, 없으면 회원 이름, 둘 다 없으면 "판매자"다(`model/following.ts`).
- 팔로워 수·♥는 목록 항목의 `followerCount`·`wishCount`다(BE PR #173, #427). 서버 팔로워 수에는 내 팔로우가 들어 있어, 해제 직후 남는 행은 1 줄어든 수를 보인다. 값이 없는 이전 서버 응답이면 그 줄을 숨긴다.
- 아바타는 기본 원이다(`profileImageUrl`은 업로드 경로가 없어 늘 빠진다). LIVE 배지는 LIVE 목록 응답(`LiveSummaryResponse`)에 `sellerId`가 없어 방송을 판매자별로 나눌 수 없으므로 숨긴다(요청서 BE-17에서 `sellerId` 추가 예정).
- [팔로잉]은 확인 없이 `DELETE /api/v1/follows/{sellerId}`를 보낸다. 해제한 행은 새로고침 전까지 제자리에 남고 버튼이 [다시 팔로우]로 바뀐다(PD-9). 해제·다시 팔로우가 성공하면 목록과 LIVE 화면이 쓰는 팔로우 목록(`followsQueryKey(memberId)`)을 다시 읽고, 실패하면 목록 위에 다시 시도 안내를 보인다(팔로우·해제는 idempotent).
- 판매자 상세 목적지가 없어(IA 메이커 정보 탭 제외) 행은 이동하지 않고, 광고는 찜 탭 실제 화면처럼 두지 않는다.
- 원본에 없는 위 동작은 노션 「FE API 연동 남은 작업」의 FE 자체 판단 89~92번에 적었다. 계약 경위는 [API 계약](./API_CONTRACT.md#알림함수신설정과-팔로우-계약-257)에 있다.

## 디자인 목업 구현 범위

- /my/wishlist와 ?tab=sellers를 사용한다. 마이페이지 관심 목록에서는 기본 찜 프로젝트 탭으로 진입한다.
- ProjectRow·SellerRow·계정 상단바를 재사용하며 실제 목업 이미지와 Figma 광고 이미지를 표시한다. 프로젝트 네 번째 뒤, 판매자 여섯 번째 뒤에 광고를 배치한다. 광고 서비스·이동 목적지는 구현하지 않는다.
- 종료 프로젝트는 이미지에만 opacity 0.3을 적용한다(1249:24305). 종료 배지·텍스트·하트 버튼을 함께 투명하게 만들지 않는다.
- 찜·팔로우 해제는 화면 목록에서 제거하고 개수를 갱신한다. 모두 제거하면 빈 상태를 표시한다. 탭은 URL로 복원하고 데이터는 페이지 이탈/새로고침 시 초기화한다.
- 프로젝트 상세는 동일한 목업 상품으로 연결한다. 판매자 상세는 목적지 미정이다. 회원·찜 API만으로 화면 필드를 모두 채울 수 없어 실제 API 연동은 제외한다.
- Tailwind·공용 토큰을 사용한다. 1199px 이하에서는 가용 폭을 사용하고, 1200px 이상에서는 공통 구매자 데스크톱 헤더·breadcrumb·793px 콘텐츠 열 안에서 프로젝트 썸네일과 광고를 확대한다. 하단 메뉴는 데스크톱에서 숨긴다.
