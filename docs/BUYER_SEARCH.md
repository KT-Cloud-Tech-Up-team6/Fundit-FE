## 구현 범위

- 기존 /search와 q, tab, status, sort, closed URL 상태를 유지한다. 탭을 눌러 LIVE에 진입하면 진행 중으로 초기화하고, 직접 URL 진입·뒤로가기에서는 지정된 상태를 복원한다.
- 최근·인기 칩은 스크롤바 없이 터치 및 마우스 드래그로 이동한다. 드래그 직후 클릭을 막고 일반 클릭·키보드 활성화는 유지한다. 최근 검색어 삭제·중복 제거·한글 조합 중 제출 방지를 지원한다.
- 실제 Figma 이미지·썸네일 크롭과 공용 SearchField, Tab, Checkbox, Chip, Dropdown, Button, EmptyState를 사용한다. ProjectRow와 SellerRow는 관심 목록과 공유한다.
- 검색 결과 개수는 실제 목업 결과에서 계산한다. Figma의 80/110/1/7은 화면 간 일치하지 않는 예시 숫자이므로 고정하지 않는다. 인기순은 목업 likes 내림차순이다.
- 진행 LIVE는 3:4 이미지와 시청자 배지, 예정 LIVE는 정사각 이미지·일정 딤·판매자·알림 버튼을 표시한다. 종료 프로젝트 필터는 프로젝트 및 진행 LIVE의 연결 프로젝트 상태에 적용한다.
- 프로젝트·LIVE 및 예정 LIVE의 프로젝트 상세는 명시적 목업 ID로 제목·판매자·이미지를 연결한다. 입력 중 LIVE 예시 4개도 각각 실제 목업 경로로 이동한다. 목업 식별자를 API 식별자로 사용하지 않는다.
- 판매자 자동완성은 해당 판매자명 검색 결과로 이동한다. 판매자 상세 목적지는 미정이어서 임의 링크를 추가하지 않는다.
- 최근 검색어·팔로우·알림은 화면 내부 목업 상태다. 영구 저장·화면 간 동기화·실제 API 검색/추천/알림/인증 가드는 포함하지 않는다. Figma의 검색어와 LIVE 예시가 달라 디자인 확인용 연관 키워드를 두며 실제 검색 품질을 구현한 것으로 취급하지 않는다.
- Tailwind와 공통 토큰이 기본이며 CSS Module은 가로 스크롤바 숨김·드래그 커서에만 사용한다. OS 키보드·상태바·홈 인디케이터는 그리지 않는다.

## 검증

- 검색 모델 테스트는 URL 복원·정규화, 종료 필터, 찜 건수 정렬, 상태 분리, 최근 검색어 처리를 확인한다.
- Storybook 11개 상태/동작에서 입력·정렬 전환·알림·한글 조합·검색 상태 복원을 확인한다.
- 별도 headless 브라우저로 실제 URL의 검색 제출·상세·라이브 자동완성 이동·뒤로가기, 외부 클릭/Escape 메뉴 닫기, 데스크톱 가로 드래그와 반응형을 확인한다.
- 한글 조합은 합성 이벤트 검증이며 실제 모바일 키보드·실기기 검증은 별도다. 공통 비활성 색상 대비 경고는 기존 디자인 토큰의 제한이다.

- #173에서 현재 원본의 화면·주석·히스토리·프로토타입을 재대조했다. 검색 모델 3개와 관련 Storybook 19개가 통과했고, 실제 검색/관심 목록/마이페이지/카테고리 이동·뒤로가기와 배너 자동 넘김·드래그·동작 줄이기를 확인했다. #165를 합친 임시 로컬 브랜치에서 320/390/768/1199/1200/1440px × 4개 경로의 가로 넘침·모바일 전체 폭·하단 접근을 검증했다. 반응형 변경은 #165에 있으며 이 문서 변경에 중복 포함하지 않는다. 실제 API, 미정 목적지, 실기기 OS 키보드는 기존 제외 범위를 유지한다.
