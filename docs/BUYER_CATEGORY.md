# 구매자 카테고리

## Design Source

- [테크·가전 1114:24119](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=1114-24119), [홈·리빙 1114:24178](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=1114-24178).
- 1114:24233은 4초 자동 스냅 배너, 1114:24234는 기본 14px Regular·선택 Medium을 지정한다.

## 구현 범위

- 팀원의 기존 카테고리 탐색·URL·하단 메뉴 복귀 로직을 유지하고 이미지·아이콘·소분류·아동 항목·간격을 갱신한다.
- 테크·가전 7개, 홈·리빙 5개 소분류는 디자인 문구를 사용한다. slug는 FE 목업이며 BE 분류 식별자로 확정하지 않는다. 다른 카테고리 소분류는 기존 placeholder를 유지한다.
- 검색 제출은 /search?q=...로 연결한다. 소분류 결과 화면은 기존 placeholder, 대분류 더보기는 목적지 미정으로 비활성이다. 별도 결과 화면·광고 목적지를 임의 구현하지 않는다.
- Figma 배너 아트워크를 사용한다. 제공된 광고는 한 종류이므로 목업 3장에 같은 이미지를 사용하고 실제 광고 집행은 하지 않는다.
- 배너는 4초 간격 자동 스냅, 터치/마우스 드래그, 키보드 가로 이동을 지원하며 스크롤바를 숨긴다. 사용자 조작 중 자동 넘김을 멈추고 종료 후 재개하며 동작 줄이기에서는 자동 넘김을 생략한다.
- compact 하단 메뉴는 54px + safe area로 공간을 확보한다. 마지막 아동 항목이 메뉴 뒤에 가려지지 않도록 한다.
- Tailwind·공통 토큰을 사용한다. 기존 CSS Modules는 상태 선택자·포커스·스크롤 스냅에만 유지한다.

## 검증

- Storybook Default, HomeLiving, Travel 및 실제 검색 제출·뒤로가기·소분류 링크.
- headless 브라우저에서 자동 넘김·드래그·동작 줄이기, 320/390/1440px 폭과 하단 접근을 확인한다.
