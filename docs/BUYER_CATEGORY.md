## 구현 범위

- 팀원의 기존 카테고리 탐색·URL·하단 메뉴 복귀 로직을 유지하고 이미지·아이콘·소분류·아동 항목·간격을 갱신한다.
- #307(2026-09-23 PM 결정)부터 카테고리 화면은 서버 목록을 받지 않는 **목업**이다. 대분류·소분류는 판매자가 고르는 확정 카테고리 7종(`src/entities/category/model/project-categories.ts`, BE project-service `V14__seed_categories_confirmed.sql`)과 같다. 영문 slug는 화면 주소용이며 BE 분류 식별자가 아니다. 이전의 디자인 문구 소분류(테크·가전 7개·홈·리빙 5개)와 대분류 13종·placeholder 소분류는 쓰지 않는다.
- 대분류 제목 아이콘은 [디자인 시스템](https://www.figma.com/design/OJkMEDf2sY4Fkh0nSSNRXe/?node-id=1-5) Streamline line 아이콘을 `public/icons/buyer-category/{slug}.svg`로 둔다. 화면 원본에는 테크·가전(`96:810`)·홈·리빙(`96:682`)만 지정되어 있어 나머지는 같은 세트에서 골랐다(#307): 뷰티 립스틱 `96:950`, 패션 넥타이 `96:951`, 푸드 포크·나이프 `96:860`, 스포츠 공 `96:999`, 캐릭터·굿즈 로켓 `96:924`(사용자 지정). `frequently_line` 규칙에 맞춰 선 두께를 1.3으로 통일했다.
- 검색 제출은 /search?q=...로 연결한다. **소분류를 누르면 무조건 LIVE 홈(`/live`)으로 이동한다**(#307). 예전 소분류 결과 주소 `/categories/{대분류}/{소분류}`로 직접 들어와도 `/live`로 넘긴다. 대분류 더보기는 목적지 미정으로 비활성이다. 별도 결과 화면·광고 목적지를 임의 구현하지 않는다.
- Figma 배너 아트워크를 사용한다. 제공된 광고는 한 종류이므로 목업 3장에 같은 이미지를 사용하고 실제 광고 집행은 하지 않는다.
- 배너는 4초 간격 자동 스냅, 터치/마우스 드래그, 키보드 가로 이동을 지원하며 스크롤바를 숨긴다. 사용자 조작 중 자동 넘김을 멈추고 종료 후 재개하며 동작 줄이기에서는 자동 넘김을 생략한다.
- compact 하단 메뉴는 54px + safe area로 공간을 확보한다. 마지막 카테고리 항목이 메뉴 뒤에 가려지지 않도록 한다.
- 1200px 이상에서는 공통 구매자 데스크톱 헤더와 1200px 콘텐츠 폭을 사용하고 하단 메뉴를 숨긴다. 카테고리 탐색은 200px 좌측 내비게이션과 4열 소분류로 배치하며 배너는 최대 793px로 표시한다.
- Tailwind·공통 토큰을 사용한다. 기존 CSS Modules는 상태 선택자·포커스·스크롤 스냅에만 유지한다.
