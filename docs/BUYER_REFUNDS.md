# 구매자 취소·환불·교환 내역

## Design Source

- [환불 내역 `891:9113`](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=891-9113).
- 디자인 파트가 오류로 삭제한 저장 버튼은 최신 원본에서 삭제를 확인했으며 구현하지 않는다.
- `/my/refunds`를 전용 `(buyer-refunds)` 그룹에 둔다.

## 구현 범위

- 취소 진행 중·취소 완료·환불 완료·교환 완료 목업 내역을 표시한다.
- 각 항목은 독립적으로 펼치고 접는다. 초기에는 ID와 관계없이 유형이 취소이고 상태가 취소 완료인 항목이 열려 있다.
- 신청 일자·사유·상품·옵션·판매가·수량과 완료된 환불 금액을 조회한다. 진행 중 취소와 교환은 환불 완료 금액을 표시하지 않는다.
- 환불 금액 영역에서 적립금 값이 없으면 해당 행을 숨기며, 명시적으로 0이면 0원으로 표시한다.
- 파란색 주석 자리에는 예시 데이터를 채우며 링크나 수정 입력으로 만들지 않는다.
- `1143:22492` 섹션 재확인 결과 필터바(총 개수·"진행 중만 보기" 토글·유형 드롭다운)는 최신 원본에 남아 있어 클라이언트 필터로 구현한다. 상태 표시는 `Badge`(`variant="warning"`|`"neutral"`)를 사용한다.
- 신청 폼·제출·취소 철회·재신청·상태 전이·환불 계산·실제 API는 범위에 포함하지 않는다. 서버 eligibility 정책을 추정하지 않는다.
- 관심 목록 PR의 상단바를 재사용하며 새 스타일은 Tailwind CSS로 작성한다.
- 색상·제목·진행 상태는 공통 토큰을 사용한다. 상세 정보의 14px/18px 조합은 대응하는 타이포그래피 토큰이 없어 로컬 예외로 유지한다. 펼치기·접기는 native details/summary를 사용한다.

## 검증

- Storybook `Features/BuyerRefunds`의 Default, Empty, ExpandHistory.
- 펼치기·접기·진행 중 및 교환 금액 미표시·저장 버튼 부재·유형·진행중 필터 동작을 검증한다.
- `pnpm test src/features/buyer-refunds/ui/buyer-refunds.test.mjs`에서 다른 ID의 취소 완료 초기 펼침과 적립금 null·0·금액 표시를 검증한다.
