## 문서 간 확인이 필요한 항목

- 요구사항 정의서는 LIVE 공급자를 “000 기반”으로 표현하므로 Amazon IVS로 확정하지 않는다.
- 판매자 등록 흐름은 별도 화면 명세가 없어 현재 라우트를 만들지 않았다.
- 프로젝트 상세의 `live-proof` 탭 노출은 LIVE 진행 여부를 서버에서 확인해야 한다.
- 환불·취소·배송조회 CTA는 FE 시간 계산이 아니라 서버 eligibility와 불가 사유를 따른다.
- `.env.example`에는 계약이 확정된 변수 이름만 추가한다.
