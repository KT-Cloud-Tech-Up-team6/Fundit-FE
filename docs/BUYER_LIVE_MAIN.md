# 구매자 LIVE 메인 와이어프레임

## Design Source

- [공유 Figma 지정 영역](https://www.figma.com/design/ifJ8lcDbezIb223WrS5m6d/?node-id=645-6663)의 `FL_B_LV_MAIN`(650:7374)을 구현한다.
- [Issue #54](https://github.com/KT-Cloud-Tech-Up-team6/Fundit-FE/issues/54).
- 영역 이름과 달리 이번 범위는 LIVE 메인만이다. 방송 시청·상세·예정·검색·더보기 화면은 새로 만들지 않는다.
- 변경 이력의 순위 목록 간격 12px, 판매자 이름 12px Medium을 적용한다. 판매자 이름은 프레임의 13px보다 변경 이력의 12px를 우선했다.

## 확인 경로

- 앱 `/live`.
- Storybook `Features/BuyerLive/Main`의 Default, NoFollowing, NotificationToggle, SearchAndNavigation.
- 390px 모바일 원본 기준이며 큰 화면에서는 같은 폭으로 중앙 정렬한다. 별도의 데스크톱 디자인을 만들지 않는다.
- 기기 상태바·홈 인디케이터는 웹 콘텐츠에 복제하지 않으며 하단 메뉴에 safe area를 적용한다.

## 구현 경계

- `/live` 페이지만 `(buyer-live)` 그룹으로 분리한다. RootLayout은 공유하고 기존 BuyerShell 및 다른 구매자 페이지는 변경하지 않는다.
- 하단 메뉴는 `shared/components/layout/BuyerBottomNavigation`으로 분리하고 `/live`에서 `activeHref`를 전달한다. 기존 SVG·크기·카테고리 비활성 상태는 유지하며 고정 위치·390px 폭·와이어프레임 배색은 호출 화면이 소유한다. 다른 구매자 화면 적용과 BuyerShell 통합은 공통 레이아웃 확정 후 진행한다.
- 기존 SearchField, 링크형 Tab/TabList, Icon을 재사용한다. 검색 높이 46px와 폰트는 기능 내부 CSS에서 맞추며 공용 기본값은 유지한다.
- 기존 검색·눈·알림·프로필 아이콘을 재사용한다. 기존 live_video는 다른 모양이므로 홈·라이브 내비게이션·카테고리·시계·알림 추가/선택은 Figma 원본 SVG를 사용한다.
- 지정 화면의 wireframe 색상은 CSS Module 내부에 한정한다. 전역 semantic 토큰과 다른 구매자 화면의 브랜드·다크 배색을 재정의하지 않는다. 이 화면 자체는 밝은 와이어프레임만 제공한다.
- 일반 카드 제목은 최대 2줄이다. 순위 카드의 긴 제목은 원본처럼 여러 줄로 표시한다.

## 목업 동작

- 신규 오픈 목록은 가로 스크롤하며 키보드 포커스를 받을 수 있다.
- 알림 설정·해제는 해당 컴포넌트의 React 상태만 변경한다. 초기에는 세 번째 팔로우 카드만 설정되어 있다. 새로고침·페이지 이탈 시 초기화하며 실제 알림은 발송하지 않는다.
- 앱과 기본 스토리에서는 팔로우 브랜드를 항상 표시해 디자인을 확인한다. NoFollowing은 섹션을 숨기는 별도 목업 시나리오일 뿐이며, 실제 로그인·팔로우 데이터에 따른 표시 정책은 미확정이다.
- 검색은 `/live/search?q=...`로 이동한다. 검색 결과는 아직 기존 placeholder다.
- 예정 라이브와 각 더보기·카드·알림함은 기존 canonical route에 연결한다. 대상 화면은 구현 전이며 목업 ID를 실제 API 식별자로 사용하지 않는다.
- 카테고리 진입 화면은 미정이므로 비활성 버튼으로 표시한다. `/categories` 또는 임의 slug를 만들지 않는다.
- API·스트리밍·실시간 순위 계산·실제 알림·영구 저장·미리보기 배포는 범위에 포함하지 않는다.

## 검증

- 알림 토글·다른 카드 상태 보존, 검색 입력/지우기, 링크 경로, 카테고리 비활성, 팔로우 기본 표시/없음 상태, 표시 배지의 카드 클릭 통과를 Storybook play에 둔다.
- 390px 및 좁은 화면에서 가로 넘침, 하단 메뉴 겹침, 검색 크기와 순위 간격·타이포를 확인한다.
- Figma 회색 탭의 낮은 명도 대비는 원본에 남아 있다. 이번 작업에서 브랜드 색상이나 접근성용 배색을 임의로 확정하지 않는다.
