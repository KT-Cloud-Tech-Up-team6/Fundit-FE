- 기존 와이어프레임 영역 645:6663의 메인(718:7005)·예정(718:7347) 구현을 유지하며 디자인을 적용한다.
- 방송 시청·상세 화면은 이번 변경 대상 프레임에 포함되지 않는다.

## 확인 경로

- 앱 `/live`, `/live/upcoming`.
- Storybook `Features/BuyerLive/Main`의 Default, NoFollowing, NotificationToggle, SearchAndNavigation, UpcomingNoFollowing.
- 390px 모바일 원본 기준이며 큰 화면에서는 같은 폭으로 중앙 정렬한다.
- 기기 상태바·홈 인디케이터는 복제하지 않으며 하단 메뉴에 safe area를 적용한다.

## 변경 사항

- Figma 원본 상품·판매자 이미지를 `public/images/buyer-live`에 저장하고 UI 목업을 `model/live-demo.ts`로 분리한다. API 응답 DTO나 실시간 데이터가 아니다.
- 신규 오픈은 정사각형, 실시간 순위·팔로우·추천 카드는 3:4 비율, 예정 카드의 시간은 이미지 위 딤으로 표시한다.
- 일반 제목은 2줄, 실시간 순위와 예정 목록 제목은 3줄로 제한한다. 알림 신청 수는 한 줄에서 말줄임한다.
- 콘텐츠 상단 16px, 섹션 사이 40px, 순위 목록 사이 16px, 콘텐츠 하단 40px를 적용한다.
- 예정 화면에 팔로우 판매자 캐러셀, 날짜별 예정 목록, 알림 신청 목록, 추천 라이브를 추가한다.
- 디자인의 날짜 제목 `9/8일 (화)`와 카드 날짜 `09.18`은 원본 그대로 표시한다. 원본의 불일치는 디자인 확인 사항이며 임의로 통일하지 않는다.
- 추천 목록은 기존 동작대로 10개씩 추가하고 30개에서 종료한다. Figma의 추천 예시 8개를 반복하며 각 카드 ID는 구분한다. 키보드용 더 불러오기 버튼을 제공한다.
- 예정 목록의 `100,00명` 표기는 기존 숫자 목업 100,000명을 유지한다. 예정 팔로우 네 번째 카드의 이미지·상품 문구 불일치는 Figma 원문 그대로 유지한다.

## 구현 경계

- 두 메인 경로만 `(buyer-live)` 그룹에서 RootLayout을 공유한다. 기존 BuyerShell 및 다른 구매자 페이지는 변경하지 않는다.
- 공용 BuyerBottomNavigation, SearchField, 링크형 Tab/TabList, Button, Badge, Avatar, Icon을 재사용한다.
- 스타일은 Tailwind와 semantic 토큰을 기본으로 사용한다. CSS Module은 포커스·스크롤바 선택자, Badge 내부 토큰, LIVE 화면 전용 내비게이션 표현에 한정한다. 기존 회색 전역 토큰 덮어쓰기는 제거한다.
- 디자인의 static LIVE 파랑은 기존 `text-primary-live` 및 Badge 내부의 blue 토큰에 매핑하며 전역 토큰은 수정하지 않는다. 내비게이션의 채움 LIVE 아이콘은 Figma SVG이며, 이 화면 안에서만 공용 아이콘의 inline mask를 재정의한다.
- 팔로우 여부는 `hasFollowing`으로 표현하며 false이면 해당 섹션을 숨긴다.
- 시작 알림은 React 상태만 변경하며 새로고침·페이지 이탈 시 초기화한다. 알림 신청 목록도 같은 상태를 사용한다.
- 검색·카드·전체보기·알림함은 기존 경로에 연결한다. 예정 목록의 더 보기 목적지는 미정이므로 비활성으로 유지한다. 목업 ID를 실제 API 식별자로 사용하지 않는다.
- 카테고리는 기존 카테고리 화면과 복귀 동작을 유지한다. API·IVS 재생·추천 알고리즘·실제 알림·영구 저장은 포함하지 않는다.

## 검증

- Storybook play에서 팔로우 표시 여부, 알림 토글과 다른 카드 상태 보존, 검색 입력/지우기, 링크 경로, 표시 배지 클릭을 확인한다.
- 브라우저에서 390px·320px·데스크톱의 가로 넘침, 두 탭 이동, 추천 목록 추가와 종료를 확인한다.
- SubscriptionKeyboard는 목록에서 해제 후 다음·이전 버튼과 빈 목록으로의 포커스 이동을 검증한다. RecommendationKeyboard는 추가된 첫 카드로의 포커스 이동과 30개 종료 안내를 검증한다.
